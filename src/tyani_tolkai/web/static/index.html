    What this is

    Two agents compete over one project: the Executor improves the artifact, and scoring (deterministic code + optional Validator) decides if it got better. The loop keeps only improvements.

    1. ＋ New project → describe the task and 🪄 generate, or fill the form → Create.
    2. ▶ Run drives the real agents; the quality curve and log update live.
    3. Live command steers the agent without stopping; Stop — at the iteration boundary.
