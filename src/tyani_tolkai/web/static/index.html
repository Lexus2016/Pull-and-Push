    // COLD = Виконавець · WARM = Оцінювач

    Що це

    Два агенти змагаються над одним проєктом: Виконавець покращує артефакт, а оцінка (детермінований код + опційний Валідатор) каже, чи стало краще. Цикл тримає лише покращення.

    1. Натисни Demo — побачиш, як крива якості повзе до 100.
    2. Новий проєкт → опиши завдання й 🪄 згенеруй, або заповни форму → Створити.
    3. Run запускає реальних агентів; графік і лог оновлюються наживо.
    4. Команда наживо керує агентом без зупинки; Stop — на межі ітерації.

    🪄 Згенерувати з опису

    Найпростіший шлях: опиши завдання словами — агент-налаштовувач сформує проєкт, а ти доведеш його у формі нижче.

    Природною мовою — що робимо, які метрики, яка мета, які обмеження.
    Який CLI-агент згенерує конфіг (має бути встановлений і залогінений).
    Заповнить форму нижче — перевір і натисни «Створити».

    Новий проєкт

    Або заповни вручну. Усе валідовується перед збереженням.

    Основне
    Унікальна назва (літери/цифри/._-). Стане текою; пізніше — через Rename.
    MVP: asymmetric — Виконавець ↔ Оцінювач.
    Агенти готові CLI — нічого писати не треба
    Який CLI редагує артефакт (встановлений і залогінений).
    Порожньо = модель за замовчуванням CLI.
    Текстовий фідбек. Бери інший провайдер (захист від «змови»).
    Ролі чого домагатись
    Головна ціль кожної ітерації.
    Звужує дії агента — допомагає збіжності.
    Оцінка бал рахує код, не LLM
    numeric: команда друкує JSON · command-exit: 0/1 за кодом · pytest-pass: % тестів.
    Запускається в пісочниці. Для numeric друкує JSON виду {"sharpe":1.8}.
    Тека з прихованими тестами — поза досяжністю Виконавця.
    Бал ≥ цього → перемога, зупинка.
    Тримати зміну, лише якщо бал виріс більше за це.
    nameнапрямweightworsttarget
    Стартовий код з чого починає виконавець
    empty: створити з нуля · copy: скопіювати наявний код · generate: агент згенерує початкову версію.
    Тека, яку скопіювати в артефакт як старт (оригінал недоторканий).
    Коли зупиняти прогін будь-яка умова зупиняє цикл
    Жорсткий стоп: найбільше кроків, навіть якщо ціль ще не досягнута.
    Стоп, якщо N змістовних змін поспіль НЕ покращили бал (застрягли).
    Скільки чекати один прогін агента, перш ніж перервати його.
    Пісочниця виконання де запускається код стратегії
    docker: ізольоване й безпечне виконання згенерованого коду · local: швидше, без ізоляції.
    Заповни назву та хоча б одну метрику.
