Проєкти

    Проєктів ще немає.
    Натисни Demo або Новий проєкт.

    Що це

    Два агенти змагаються над одним проєктом: Виконавець покращує артефакт, а оцінка (детермінований код + опційний Валідатор) каже, чи стало краще. Цикл тримає лише покращення (git hill-climbing).

    1. Спершу натисни Demo — побачиш, як крива якості повзе до 100.
    2. Новий проєкт → заповни форму (підказки під кожним полем) → Створити.
    3. Run запускає реальних агентів; графік і лог оновлюються наживо.
    4. Команда наживо керує агентом без зупинки; Stop зупиняє на межі ітерації.

    🪄 Згенерувати з опису

    Найпростіший шлях: опиши завдання словами — агент-налаштовувач сформує проєкт, а ти доведеш його у формі нижче.

    Природною мовою — що робимо, які метрики, яка мета, які обмеження.
    Який CLI-агент згенерує конфіг (має бути встановлений і залогінений).
    Заповнить форму нижче — перевір і натисни «Створити».

    Новий проєкт

    Або заповни вручну. Усе валідовується перед збереженням.

    Основне
    Унікальна назва. Стане текою проєкту; після створення не змінюється тут (є Rename).
    MVP: asymmetric — Виконавець ↔ Оцінювач. Симетричний (двобій) — згодом.
    Агенти готові CLI — нічого писати не треба
    Який CLI-агент редагує артефакт. Має бути встановлений і залогінений у системі.
    Порожньо = модель за замовчуванням цього CLI.
    Дає текстовий фідбек. Бери інший провайдер, ніж Виконавець (захист від «змови»).
    Ролі чого домагатись
    Головна ціль, яку агент намагається досягти кожною ітерацією.
    Звужує дії агента. Необов'язково, але дуже допомагає збіжності.
    Оцінка звідки береться бал (рахує код, не LLM)
    numeric: команда друкує JSON чисел · command-exit: 0/1 за кодом виходу · pytest-pass: % тестів.
    Запускається в пісочниці всередині артефакту. Для numeric має друкувати JSON виду {"sharpe":1.8}.
    Тека з прихованими тестами — поза досяжністю Виконавця (щоб не «підкрутив» собі бал).
    Коли бал ≥ цього — цикл зупиняється з перемогою.
    Тримати зміну лише якщо бал виріс більше, ніж на це. Захист від випадкового шуму.

    Seed · Ліміти · Sandbox
    empty: з нуля · copy: скопіювати наявний код · generate: агент згенерує старт.
    Тека, яку скопіювати в артефакт (оригінал недоторканий).
    Жорсткий стоп за кількістю кроків.
    Стоп, якщо N змістовних кроків поспіль без покращення.
    Таймаут на один прогін агента.
    docker: ізольоване виконання коду (безпечніше) · local: швидше, без ізоляції.
    Заповни назву та хоча б одну метрику.

    Керування та прогрес

    Запускай, зупиняй і скеровуй прогін. Графік — крива якості; лог — рішення keep/discard щокроку.
