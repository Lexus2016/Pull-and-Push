# Short steps by default: every agent reasons at "medium"

- **Every agent in every role now reasons at `medium` by default** — executor, reviewer and helpers, on all five engines (claude and agy `--effort`, grok `--reasoning-effort`, codex `model_reasoning_effort`, opencode `--variant`). The loop is many short steps; one long think on a single step only slows it. Until now an agent without an `effort` setting used your personal CLI default (claude "xhigh", grok "high"): one Grok executor turn reasoned for the whole 10-minute timeout without touching a file. Verified live: with the new default each engine wrote its file in 7–45 s.
- **Raise it only where you mean to:** `agents: {executor: {engine: claude, effort: high}}`. Projects that already set `effort` keep their value.
- READMEs (English, Українська, Русский), the research-kit docs and the research skill updated to match.
