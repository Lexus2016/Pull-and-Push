# Grok support, agy fixed, cleaner reviews, honest finish reasons

- **Grok (xAI Grok Build) is a supported agent.** Executor: `grok --always-approve --cwd <artifact> -p <brief>`; reviewer and helper run with Write / Edit / Bash denied (a headless `grok -p` does write files otherwise — checked with a write-bait: nothing written). Verified live: a bug fix in a file, a JSON helper answer, and a real research iteration. Install: `curl -fsSL https://x.ai/cli/install.sh | bash`; ⚙ Settings shows it with its version.
- **Reasoning effort per agent:** `agents: {executor: {engine: grok, effort: medium}}` (claude `--effort`, grok `--reasoning-effort`, codex `model_reasoning_effort`). Unset = the CLI's own default — your personal setting, often "high": one Grok turn reasoned for the whole 10-minute timeout without touching a file. Helpers (wizard, metric proposals, bot analysis) always use "medium".
- **Codex reviews are clean.** With `codex` as reviewer, the feedback passed to the executor used to carry codex's banner, its settings and an echo of the entire reviewer prompt — now it is only codex's final answer (`--output-last-message`). This affected every run with the recommended claude + codex pair.
- **`agy` works as an agent now.** The loop launched it as `agy -p --dangerously-skip-permissions …`; agy ≥ 1.2 takes the word after `-p` as the prompt, so it silently ignored every task — the real reason it was marked "not recommended". The prompt now goes into `--print`; verified with agy 1.2.13 (a bug fix, a JSON helper answer, a real research iteration: speed-up 0.02 → 2.91 with all constraints kept).
- **Honest finish reason.** A project made from a research kit that reaches its target on the first iteration now finishes as *target reached*, not as "the seed already meets the target" (a false alarm, also in the macOS notification) — the pre-flight had measured the seed below the target.
- **READMEs (English, Українська, Русский)** updated throughout: the macOS app and its updates, ⚙ Settings, token sign-in, notifications, the `custom` template, agents and effort, security, tests.
- A flaky test (port 8765 in TIME_WAIT) fixed.
