# Real cost, confined agents, a readable live log

- **The spend is what the agents report, not a guess.** Every engine now streams JSON (claude stream-json, codex --json, grok streaming-json, opencode --format json, agy stream-json). claude and grok report each call's dollar cost; codex, agy and some opencode models report tokens, priced at `limits.usd_per_mtok` (cache reads at 10%). The old estimate counted only the prompt and the answer text (characters / 4) and missed everything an agent reads and thinks — a one-line task measured **$0.21** on claude where it guessed almost nothing, so `budget_usd` was close to blind. Every executor retry is charged now, not only the last one. The status shows `$X.XX`, or `≈ $X.XX` when a call reported nothing; `research status --json` adds `tokens` and `cost_measured`.
- **Agents no longer carry your personal setup into the loop.** Measured on a one-line task before the fix: codex read `~/.codex/MCP.md` and called your `tqmemory` (140k input tokens), grok and agy ran your rituals, opencode printed your activation token, claude ran your SessionStart hooks. Now claude starts without hooks and skills, codex without the MCP servers in your config (a one-line task: 45 s → 10–16 s — they no longer start on every call) and with the loop's brief as a developer message, grok without the Claude/Codex rules, skills and MCP it imports, opencode without plugins and `~/.claude` rules. agy has no switch for this — it still reads your `GEMINI.md` and MCP servers; the brief now leads its prompt.
- **A readable live log.** `agent.log` shows one line per action (`▸ Write solution.py`, `▸ $ pytest → exit 0`) and the agent's own words — no raw JSON; claude's log used to stay empty until the step ended.
- **Peeking at the judge is flagged.** In a live arena check grok ran `sqlite3` on the run's database, searched the disk with `rg`, found the referee's source and read the answer — the "work only in your folder" brief did not stop it, and nothing short of an OS sandbox can. Now every executor action that reaches outside the artifact folder is marked `⚠` in the live log, recorded on the iteration, explained to the executor in its next brief, and counted in `research status --json` (`outside`).
- **"The agent only reasoned" is said out loud.** An executor step that eats the whole timeout without a single action is reported as such, with what to change (a lower effort, a narrower task, or a longer timeout).
- **A crashed claude run is no longer mistaken for a rate limit** (its stream reports the limit state on every run) — that used to pause the research instead of retrying.
- **Any engine can be an arena rival.** The ban on opencode, agy and grok dated from before each engine was given its folder explicitly.
- The budget warning now names the engines it cannot price (claude and grok need no `usd_per_mtok`).
- READMEs (English, Українська, Русский) and the research skill updated.
