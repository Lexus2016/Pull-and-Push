# The app speaks the dashboard's language

- Menus, About, dialogs, notifications and the update windows now follow the dashboard's **EN / UA / RU** switch instead of the system language. Our menus switch at once; the few items macOS adds by itself (e.g. *Quit and Close All Windows*) and Sparkle's update window follow from the next launch.
- The choice is remembered between launches — also when the dashboard ends up on another port.
- Self-tests no longer touch the installed app's settings (language, window position, web storage): test runs use a throw-away store.
