# P3.1 Scoring Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A vetted backtest engine that scores a bot which runs as a SUBPROCESS speaking a streaming JSON-lines protocol — the engine feeds bars one at a time (no absolute timestamps), the bot replies with a desired position per bar (look-ahead physically impossible), and the engine computes all PnL/metrics itself on a seeded-but-hidden OOS tail. Subprocess only (no OS sandbox yet — P3.2); tested with a trusted reference adapter; a loud guard forbids untrusted bots until P3.2.

**Architecture:** Pure Python, cross-platform. Generalizes `templates/btcusdt-futures/harness/run_backtest.py` (which runs `signals()` IN-PROCESS) into engine(bars, orders)->metrics + a subprocess protocol driver. Spec: [`docs/design/p3-scoring-core.md`](../design/p3-scoring-core.md).

**Tech Stack:** Python 3.10+, stdlib `subprocess`/`json`/`hashlib`, pytest.

```python
# src/tyani_tolkai/bot_protocol.py
"""Wire protocol for the P3 bot evaluation core (spec: docs/design/p3-scoring-core.md).

JSON-lines over the bot subprocess's stdin/stdout. Strict request->response. Bars carry NO
absolute timestamp (only OHLCV + a counter) so the bot cannot fingerprint the date range and
recall it from training memory. The scored OOS tail starts at a seeded-but-hidden offset.
"""
from __future__ import annotations

import hashlib
import json

INIT = "init"
READY = "ready"
BAR = "bar"
ORDER = "order"
END = "end"

# OOS split is drawn from this band of the bar count, using a per-project seed.
OOS_LO = 0.60
OOS_HI = 0.80


def encode(msg: dict) -> str:
    """Serialize one protocol message to a single newline-terminated JSON line."""
    return json.dumps(msg, separators=(",", ":")) + "\n"


def decode(line: str) -> dict:
    """Parse one protocol line into a dict. Raises ValueError if it is not a JSON object."""
    obj = json.loads(line)            # raises json.JSONDecodeError (subclass of ValueError)
    if not isinstance(obj, dict):
        raise ValueError("protocol message must be a JSON object")
    return obj


def seeded_oos_start(n_bars: int, *, seed: str, lo: float = OOS_LO, hi: float = OOS_HI) -> int:
    """Deterministic, bot-hidden start index of the scored OOS tail.

    Reproducible for a given (n_bars, seed) so the determinism check works, but unpredictable
    to the bot (which never sees the seed), so it cannot behave differently on the scored tail.
    """
    if n_bars <= 0:
        return 0
    lo_i = int(lo * n_bars)
    hi_i = int(hi * n_bars)
    if hi_i <= lo_i:
        return min(lo_i, n_bars)
    digest = hashlib.sha256(f"{seed}:{n_bars}".encode()).hexdigest()
    span = hi_i - lo_i
    return lo_i + (int(digest, 16) % span)
```

### Task 4: subprocess driver `drive_bot`

**Files:** Create `src/tyani_tolkai/bot_runner.py`, `tests/test_bot_runner.py`.

Engine-side driver. Spawns a bot `cmd` (list[str]) as a subprocess with `close_fds=True`, an
empty `cwd` (temp dir), text pipes; does the init handshake; streams each bar and reads exactly
one `order` per bar; enforces a per-read timeout and a total wall-clock cap; caps total bytes
read; on ANY violation (bad JSON, wrong type, wrong `n`, timeout, crash, byte cap) raises
`BotProtocolError` with a GENERIC message (no bot output echoed back into the optimizer path);
ignores nothing — every line must be a valid expected reply. Always terminates the child.
